# Accepted design

This index records Status's accepted design choices and tradeoffs. The area
files carry the same weight as [AGENTS.md](../../AGENTS.md).

Read the relevant area files before proposing a change or recording a finding
or audit entry. Revisit a decision when the owner asks or new evidence changes
its documented impact. Record new owner-accepted decisions in the relevant area
file.

- [Transport](accepted-design/transport.md) covers simulated HTTP errors,
  response delays, and request timeouts.
- [Project workflow](accepted-design/project-workflow.md) covers the scope of
  Docker image validation before publication.
